#Auto Grader

A web-based application that automatically evaluates and grades student submissions, providing instant feedback through a React frontend and Node.js backend.

#Description

Auto Grader is a full-stack web application designed to simplify and automate the grading process. It allows users to submit answers through an intuitive React interface, which are then processed and evaluated by a Node.js backend. The system calculates results instantly and returns feedback to the user in real time.

This project helps reduce manual grading effort, improves efficiency, and ensures consistent evaluation. It is ideal for quizzes, assignments, and other assessment-based systems. The architecture is scalable and can be extended to support authentication, multiple question types, and database storage.

#Getting Started

Follow the instructions below to set up the project locally on your machine.

#Dependencies

Make sure you have the following installed:

Node.js v14 or higher

npm (comes with Node.js)

Git

Modern web browser (Chrome, Edge, Firefox)

#Installation

Clone the repository:

git clone https://github.com/your-username/auto-grader.git
cd auto-grader

Install backend dependencies:

cd backend
npm install

Start the backend server:

npm start

The backend will run on:

http://localhost:5000

Open a new terminal and install frontend dependencies:

cd frontend
npm install

Start the frontend application:

npm start

The frontend will run on:

http://localhost:3000
